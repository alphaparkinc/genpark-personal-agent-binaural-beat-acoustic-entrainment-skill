## 🛠️ MCP Tools Exposed
- `synthesize_binaural_carrier_frequencies`: Generate left/right channel frequencies for desired target EEG brainwave state.
- `generate_acoustic_entrainment_session_plan`: Synthesize a 45-minute timed audio ladder session transitioning from high-beta to target state.
